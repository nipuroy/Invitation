## 🚀 GitHub থেকে রান করার নিয়মাবলী (How to Run Locally)

GitHub থেকে প্রজেক্টটি ডাউনলোড বা ক্লোন করার পর আপনার কম্পিউটারে চালু করতে নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: প্রজেক্ট ডিরেক্টরিতে ডিপেনডেন্সি ইন্সটল করুন
টার্মিনাল বা কমান্ড প্রম্পট (cmd / PowerShell / Bash) ওপেন করে প্রজেক্ট ফোল্ডারে লিখুন:
```bash
npm install
```
*(এটি প্রয়োজনীয় সব প্যাকেজ যেমন React, Tailwind CSS, Vite ইত্যাদি ইন্সটল করবে)*

### ধাপ ২: লোকাল সার্ভার চালু করুন
ইন্সটল সম্পন্ন হলে নিচের যেকোনো একটি কমান্ড দিন:
```bash
npm run dev
```
অথবা
```bash
npm start
```
এরপর ব্রাউজারে `http://localhost:3000` ঠিকানায় যান।

## 🌐 গিটহাব পেজেসে লাইভ চালানোর নিয়ম (GitHub Pages Live Link)

GitHub Pages-এ সরাসরি ওয়েবসাইট হিসেবে চালাতে নিচের যেকোনো **একটি** সহজ উপায় বেছে নিন:

### উপায় ১: GitHub Actions (সবচেয়ে আধুনিক ও অটোমেটিক) ⭐
প্রজেক্টটিতে ইতিমধ্যে `.github/workflows/deploy.yml` যুক্ত করা আছে।
1. GitHub-এ আপনার রিপোজিটরিতে যান।
2. **Settings** ট্যাবে ক্লিক করুন।
3. বাম পাশের মেনু থেকে **Pages**-এ যান।
4. **Source** ড্রপডাউনে ক্লিক করে **"GitHub Actions"** সিলেক্ট করুন।
5. ব্যস! ১ মিনিটের মধ্যে আপনার সাইটটি লাইভ হয়ে যাবে এবং লিংক পেয়ে যাবেন।

### উপায় ২: /docs ফোল্ডার নির্বাচন (Branch Deploy)
প্রজেক্টের `docs/` ফোল্ডারে প্রস্তুতকৃত প্রোডাকশন ফাইল যুক্ত আছে।
1. GitHub-এ আপনার রিপোজিটরিতে যান।
2. **Settings** > **Pages**-এ যান।
3. **Source**: "Deploy from a branch" রাখুন।
4. **Branch**: `main` (অথবা `master`) সিলেক্ট করুন এবং পাশের ড্রপডাউন থেকে **`/docs`** সিলেক্ট করে **Save** দিন।

## 🚀 কম্পিউটারে লোকালভাবে রান করার নিয়ম (How to Run Locally)

GitHub থেকে প্রজেক্টটি ডাউনলোড বা ক্লোন করার পর আপনার কম্পিউটারে চালু করতে:

### ধাপ ১: প্যাকেজ ইন্সটল করুন
টার্মিনাল বা কমান্ড প্রম্পটে প্রজেক্ট ফোল্ডারে লিখুন:
```bash
npm install
```

### ধাপ ২: সার্ভার চালু করুন
```bash
npm run dev
```
*(অথবা `npm start`)*
এরপর ব্রাউজারে **`http://localhost:3000`** এ যান।

## ⚠️ কেন আগে "আমন্ত্রণ পত্র লোড হচ্ছে..." আটকে ছিল?
GitHub Pages কোনো সাধারণ এইচটিএমএল হোস্ট, কিন্তু React/TypeScript প্রজেক্ট ব্রাউজারে সরাসরি চালানোর জন্য আগে বিল্ড করতে হয় (Raw TypeScript ব্রাউজার সরাসরি রান করতে পারে না)। তাই GitHub Settings থেকে **GitHub Actions** অথবা **Branch: /docs** সিলেক্ট করলেই স্বয়ংক্রিয়ভাবে বিল্ড ফাইল রান হবে এবং কার্ডটি সঙ্গে সঙ্গে লোড হবে।
