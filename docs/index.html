আমন্ত্রণ পত্র লোড হচ্ছে...

বিরল উপজেলা ছাত্রকল্যাণ সমিতি, হাবিপ্রবি

⚠️ পেজটি লোড হতে সমস্যা হলে:

  • GitHub Pages-এ চালাতে: Settings > Pages > Build and deployment থেকে GitHub Actions সিলেক্ট করুন অথবা Branch এ /docs সিলেক্ট করুন।
  • পিসিতে লোকালভাবে চালাতে: টার্মিনালে npm install এবং এরপর npm run dev দিন।
  • সরাসরি বিল্ড ভার্সন দেখতে: docs/index.html অথবা dist/index.html এ ক্লিক করুন।
